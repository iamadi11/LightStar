# Review

## Responsibility

Independently review the actual diff. Capable of rejecting work.

## Inputs

- Diff since task start
- Spec / work order
- Test results

## Outputs

- Standards findings
- Spec fidelity findings
- Approve / request changes / reject

## Boundaries

- Passing tests alone are not approval.
- Must read the diff.

## Success

Either approved with residual risks listed, or returned with concrete revision asks.
